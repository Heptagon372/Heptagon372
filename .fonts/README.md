# Fonts

Both under the SIL Open Font License 1.1 — free to bundle and redistribute.

| File | Family | Source |
|:--|:--|:--|
| `Orbitron.ttf` | Orbitron (variable, 400–900) | https://fonts.google.com/specimen/Orbitron |
| `JetBrainsMono.ttf` | JetBrains Mono (variable, 100–800) | https://fonts.google.com/specimen/JetBrains+Mono |

They're committed so the card workflow never depends on a font download, and so
`gen_cards.py` can bake text to SVG paths — that way the cards look the same in
every browser without loading a webfont.
